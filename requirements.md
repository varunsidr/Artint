# Product requirements

Updated: 2026-10-29. Milestone A local evidence: [validation](docs/validation.md).

Proposed next-release sequence and evaluation methodology: [roadmap](docs/roadmap.md). New requirements below describe planned work, not implemented or validated capabilities.

## Goal and release scope

Build a dependable local research workspace that captures permitted public articles, produces clean reading PDFs, organizes a personal library, and creates inspectable source-grounded research. The first release serves one user on one computer. Initial pilot audience remains to be validated.

Keep article PDFs and analytics separate. Local AI remains optional: capture, PDF export, library access, and keyword search must work without Ollama. Article text stays on the computer when the default loopback Ollama endpoint is used; publisher fetching still requires network access. A configured remote model endpoint changes that privacy boundary and must be made clear to the user.

## Acceptance requirements

Public distribution must exclude local libraries, downloaded publisher text, reading PDFs, private configuration and backups. The README must identify the validated platform, model requirements, limitations and unproven quality targets. The public preview must be reproducible from original synthetic fixtures without network or model calls, and refuse to overwrite existing destination files. MIT covers project code and original fixtures; it does not grant rights to publisher content or dependency code. Pushes and pull requests must run the Windows/Python 3.13 test workflow, including the deterministic browser fixture.

## Explicitly deferred capabilities

- Public multi-user hosting, billing, team collaboration, and scheduled monitoring.
- Recursive website crawling, browser-based search/discovery, authentication/paywall bypass, and automatic OCR.
- Embedded article images, pixel-faithful website archives, and comprehensive multilingual typography.
- Independent fact checking: source-grounded output describes the saved evidence and may still contain errors.

Adding one of these requires a concrete user need and updated acceptance criteria.
